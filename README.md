# Molecular Dynamics Simulation

## Overview

Python implementation and analysis of molecular dynamics simulations of Lennard-Jones particles in the microcanonical (NVE) ensemble.

This project explores the relationship between molecular interactions, thermodynamic properties, and statistical mechanics through numerical simulation.

## Objectives

- Implement molecular dynamics simulations using the Lennard-Jones potential.
- Integrate equations of motion using the Velocity-Verlet algorithm.
- Investigate energy conservation and thermodynamic equilibrium.
- Calculate pressure using the virial expression.
- Analyse the effect of density and system size on simulation results.
- Estimate chemical potential using the Widom insertion method.

## Methodology

The simulations use a Lennard-Jones pair potential to describe intermolecular interactions. Particle trajectories are generated by numerically integrating Newton's equations of motion using the Velocity-Verlet algorithm.

Thermodynamic properties are calculated from the resulting trajectories and compared with theoretical predictions and reference data.
